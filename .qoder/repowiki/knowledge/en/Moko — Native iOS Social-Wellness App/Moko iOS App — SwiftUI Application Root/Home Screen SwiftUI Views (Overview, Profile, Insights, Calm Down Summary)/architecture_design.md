Pure SwiftUI presentation layer under `UIScreens/homeScreens/` with no business logic — data is pulled via `@Query` from SwiftData models (`Profile`, `Quest`, `InsightsModel`, `CalmDownModel`, `OnboardingState`) and mutations go through shared services like `DailyMissionService` and `QuestProgress`. Top-level entry points are `Overview.swift` (today's mission + Growth cards), `ProfileOverView.swift` (profile sheet launched from the Overview avatar), plus sibling screens `OverviewDebriefDone.swift`, `OverviewResumeScreen.swift`, `Radarinfosheet.swift`. Sub-folders group related screens: `Insights/` holds the four-parameter radar analysis; `Summary_CalmDown/` holds the exercise-time summary chart; `ProfileOverView/` contains the nested profile sub-screens (account & data, achievements list/detail, notifications, settings overview, delete-account confirmations, sign-out confirmation). Navigation between these screens uses `NavigationStack` / `NavigationLink` for push destinations and `.sheet()` with `.presentationDetents([.large])` for modal sheets. Charts are built with the native `Charts` framework (line/bar marks) while custom diamond/radar visuals are hand-drawn via a local `DiamondShape: Shape` and `Path` geometry.
