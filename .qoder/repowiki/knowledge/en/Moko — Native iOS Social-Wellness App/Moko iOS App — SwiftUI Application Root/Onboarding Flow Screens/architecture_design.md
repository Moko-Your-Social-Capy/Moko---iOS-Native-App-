Single-screen SwiftUI module under `UIScreens/Onboarding/`. `onboardingFlow.swift` defines the `OnboardingStep` enum (`nameEntry`, `ageEntry`, `welcome`) and an `OnboardingFlow` root view that wires a `NavigationStack` with `navigationDestination(for:)` to drive the linear progression. Each step is a self-contained `View`: `FamiliarCarouselView` (situations carousel), `NameEntryView` (text input), `AgeEntryView` (scroll-wheel picker), and `WelcomeView` (final greeting). State is persisted via `@AppStorage` keys (`userName`, `userAge`, `hasCompletedOnboarding`) in the flow coordinator; child views receive data through parameters and callbacks (`onContinue`). Visual styling is centralized in `Colors.swift`, which extends `Color` with static theme constants backed by `MokoTheme` and a hex initializer. A shared `onboardingNavigationBar()` View modifier standardizes the system nav bar appearance across steps.
