Each subdirectory is an independent Rive project with its own `rive.yaml` manifest declaring a `name`, a `main` state-machine name, and an `output.dir` pointing back into `Moko/Resources/Animations` (the shared asset bundle). The `.rml` scene files are authored in each project's folder; compiled outputs land under `build/` during development and the final compiled animations are copied into the app's resource tree. `MokoCompleteRive` is the exception — it outputs directly to the parent directory rather than the shared Animations folder. Assets such as fonts (`BadgeLabel.ttf`) and sprite sheets (`hi_frames/`, `meditating_moko.png`, `welcomeCapy.png`, `badge_face.png`) live alongside their scene definitions. There is no cross-project dependency: each animation is self-contained and referenced by the host app via its compiled output path.
