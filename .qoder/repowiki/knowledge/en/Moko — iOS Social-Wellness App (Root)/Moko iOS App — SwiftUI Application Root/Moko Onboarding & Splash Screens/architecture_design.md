Four sibling SwiftUI `View` structs form a linear onboarding funnel: `SplashScreenView` (animated brand reveal with auto-advance), `OnboardingIntroView` (mascot greeting + 'Let's Begin'), and `OnboardingAuthView` (email/password or social sign-in). Each screen exposes an `onFinished`/`onLetsBegin`/`onAuthenticated` closure to hand control back to the parent navigation stack. Shared assets live alongside the views: `MokoTheme.swift` centralizes design tokens (brand colors, semantic mappings like `background`/`cardBackground`/`textPrimary`) plus haptic helpers (`playFeedback`, `playNotificationFeedback`) and reusable components (`MokoPrimaryButtonStyle`, `MokoFlowerOrnament`). The animated capybara mascot is rendered via Rive (`MokoAnimatedMascotView` wrapping `AsyncRiveUIViewRepresentable` loading `MokoWelcomeRive.riv`). Authentication logic is delegated outward: `OnboardingAuthView` holds `AuthService` and `GoogleAuthService` from the `Auth` module and calls into `Supabase` for email/password flows, while Apple/Google callbacks are injected as closures so this module stays UI-only. A static Lottie file `moko_jump_wave.json` is bundled for potential future animation use.
