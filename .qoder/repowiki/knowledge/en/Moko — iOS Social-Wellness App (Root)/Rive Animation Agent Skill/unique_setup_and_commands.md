The skill expects the Rive CLI on PATH (or at `~/.rive/bin/rive`) and Python 3 with `pip install pillow` for the frame-diff tool. Key workflows are invoked from the skill's root: `python3 tools/thin_keys.py <project>` rewrites `scene.rml` in place, and `python3 tools/frame_diff.py OLD_DIR NEW_DIR /tmp/diff [artboard] [--data k=v] [times...]` compares rendered output across two RML trees.
