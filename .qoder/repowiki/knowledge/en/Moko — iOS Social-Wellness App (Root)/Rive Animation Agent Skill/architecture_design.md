The module is an agent-skill bundle consumed by the `.agents` system. `skills-lock.json` pins a single external skill (`iabhi1610/rive-animation-skill`) fetched from GitHub, with its entry point declared as `SKILL.md`. The skill directory under `.agents/skills/rive-animation/` contains: `SKILL.md` (the human-readable authoring guide covering state management, sound sync, keyframe thinning, responsive layout, and device testing), `tools/thin_keys.py` (Python script to reduce redundant keyframes via Ramer–Douglas–Peucker), and `tools/frame_diff.py` (Python script using Pillow to compare rendered frames between two RML projects). Dependency direction is one-way: the skill references the Rive CLI (`rive schema`, `rive inspect`, `rive . --screenshot`) and Python 3 + Pillow; nothing in this module imports or is imported by application code — it is purely documentation plus helper scripts for the agent workflow.
