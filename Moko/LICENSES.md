# Visual asset sources and licenses

## Shared foliage SVG assets

The app uses recolored vector derivatives of these CC0 SVG Repo files. Original downloaded files are kept in `Moko/Moko/Resources/FoliageSVG/*-original.svg`; the recolored versions are in the matching asset catalog image sets.

| Asset | Source | License | Recolor |
|---|---|---|---|
| `FoliageBranch` | [Leaf Branch, SVG Repo](https://www.svgrepo.com/svg/487510/leaf-branch) | CC0 | Sage `#829A77` |
| `FoliageBush` | [Bushes Bush, SVG Repo](https://www.svgrepo.com/svg/246136/bushes-bush) | CC0 | Sage `#92AA89` |
| `FoliageGrass` | [Grass Leaves Silhouette, SVG Repo](https://www.svgrepo.com/svg/27736/grass-leaves-silhouette) | CC0 | Sage `#A6BA9A` |

SVG Repo marks each source page as CC0. No Moko character artwork is included in these foliage assets.

## Quest category scene images

The 16 WebP files in `Moko/Moko/Assets.xcassets/QuestScene*.imageset/` were generated for this project with OpenAI ImageGen from the user's scene descriptions. They are original generated outputs, not third-party SVGs or stock images. Under the [OpenAI Terms of Use](https://openai.com/policies/row-terms-of-use/), the user owns the Output as between the user and OpenAI, to the extent permitted by applicable law.

Each category has a light and a dimmed dark appearance variant:

| Category | Asset set |
|---|---|
| Work | `QuestSceneWork` |
| Friends | `QuestSceneFriends` |
| Family | `QuestSceneFamily` |
| Date / Dating | `QuestSceneDate` |
| Interview | `QuestSceneInterview` |
| Events | `QuestSceneEvents` |
| Calm / Relax | `QuestSceneCalm` |
| Explore | `QuestSceneExplore` |
